🧠 VibeLogic：让 Cursor 重构不再“脑残”
当你的项目超过 1000 行，Cursor 是否开始乱改代码？逻辑是否开始崩盘？

VibeLogic 不是代码生成器，它是你和 AI 之间的**“图纸监工”**。它强行锁定 AI 的思维边界，防止它在重构时把你的底层架构改得稀碎。

🎯 它解决什么问题？
如果你在用 vibecoding模型 开发大中型项目，一定遇到过这些“红温”时刻：

越权乱改：你让他改个登录按钮，他顺手把你数据库连接逻辑给删了。

上下文坍塌：文件一多，AI 顾了头就忘了尾，写出一堆看似正确实则跑不通的“面条代码”。

黑盒焦虑：你不知道 AI 脑子里是怎么想的，直到它把代码彻底写烂。

💡 怎么用？（只需三步）
第一步：挂载文件，强迫 AI 画图纸 🔍

一键挂载你想修改的所有文件。VibeLogic 会强制 AI 提取代码骨架，先画出一份 架构拓扑图 (Mermaid)。

大白话： 先让 AI 把它的施工思路“画”给你看，图纸不通过，不准开工。

第二步：审计图纸，你才是架构师 🎨

在侧边栏直接看图。发现 AI 的逻辑理解偏了？直接输入建议，AI 会实时修改图纸，直到逻辑无懈可击。

大白话： 你当总工，AI 当绘图员。你们在图纸上达成共识，避免后期推倒重来。

第三步：导出指令，给 AI 戴上“紧箍咒” 🔒

点击【导出重构施工单】，系统会自动生成一份包含“物理锁定协议”的秘密文档并复制代码。

回到 Cursor 对话框，直接粘贴回车。

大白话： 这份文档里有给 AI 戴的“紧箍咒”，强制它必须按图施工，严禁修改图纸之外的任何核心代码。

🔥 核心杀手锏

物理级死锁：利用底层拦截技术，从源头上切断 AI 盲目发散的越权修改。

Token 节省 90%：通过高维拓扑抽象和缓存协议，大幅降低重构时的 API 费用。

认知净化流：自动剔除 AI 的思考废话，只给你最精准的指令集。

自愈引擎：AI 画图语法崩了？底层探针会在数秒内自动呼叫算力完成修复，你无需操心。

🚀 快速安装
在 GitHub Release 页面下载最新的 .vsix 文件。
在 VS Code 插件面板选择 Install from VSIX。
填入你的 API Key，开启“上帝视角”编程体验。
