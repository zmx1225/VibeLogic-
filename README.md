🧠 VibeLogic：让 Cursor 重构不再“脑残”
当你的项目超过 1000 行，Cursor 是否开始乱改代码？逻辑是否开始崩盘？
VibeLogic 并非代码生成器，它是你和 AI 之间的**“施工图纸”与“监工”**。它能强行锁定 AI 的思维，防止它在重构时破坏你的核心架构。

🎯 它解决什么问题？
当你用 Cursor 或 Claude 进行大面积重构时，必然会遇到这三个死穴：
·越权乱改：你让他改登录，他顺手把你数据库连接逻辑给删了。
·上下文坍塌：文件太多，AI 顾了头顾不了尾，写出一堆跑不通的代码。
·黑盒焦虑：你完全不知道 AI 脑子里是怎么规划逻辑的，直到它把代码写烂。

💡 怎么用？（只需三步）
1. 挂载分析 (Map it) 🔍
一键挂载你想重构的所有文件。VibeLogic 会强制 AI 先吐出一份架构图 (Mermaid)。
直白点说：让 AI 先把“施工图”画出来给你看，不准直接开工。

2. 图纸审计 (Review it) 🎨
在侧边栏直接查看架构图。发现 AI 逻辑错了？直接输入建议，AI 会实时修改图纸，直到你满意为止。
直白点说：你当架构师，AI 当绘图员。图纸没点点头，AI 不许碰代码。

3. 降维处决 (Lock it) 🔒
点击【导出重构施工单】，系统会生成一份包含“物理锁定协议”的秘密文档并自动复制代码。
回到 Cursor，粘贴指令，回车。
直白点说：这份文档里有给 AI 戴的“紧箍咒”，强迫它必须按图纸施工，严禁修改图纸之外的任何代码。

🔥 核心杀手锏
物理级死锁：利用底层拦截技术，从源头上切断 AI 盲目发散的越权修改。

Token 节省 90%：通过高维拓扑抽象和缓存协议，大幅降低重构时的 API 费用。

认知净化流：自动剔除 AI 的思考废话，只给你最精准的指令集。

自愈引擎：AI 画图语法崩了？底层探针会在数秒内自动呼叫算力完成修复，你无需操心。

🚀 快速安装
在 GitHub Release 页面下载最新的 .vsix 文件。

在 VS Code 插件面板选择 Install from VSIX。

填入你的 API Key，开启“上帝视角”编程体验。
